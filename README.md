# Dinner Please Bot

Telegram-бот с рецептами из приложенного PDF. Бот отвечает в чате только тогда, когда его упомянул пользователь из allowlist. Категории, меню с пагинацией и рецепты открываются через inline-кнопки; предыдущее сообщение бота при каждом переходе удаляется.

Рецепт длиннее лимита Telegram в 4096 символов отправляется двумя последовательными сообщениями. Кнопка возврата находится во второй части и удаляет обе части перед показом меню.

## Запуск

1. Создайте бота через `@BotFather` и добавьте его в нужный чат.
2. Передайте токен через окружение (не коммитьте его):

   ```bash
   export BOT_TOKEN='123456:telegram-token'
   go run ./cmd/bot -config config/config.yaml
   ```

3. Упомяните бота в чате с аккаунта `@pav_kozlov` или `@angelina_pos`.

Все параметры лежат в `config/config.yaml` и могут быть переопределены переменными окружения:

- `BOT_TOKEN` — токен бота;
- `BOT_ALLOWED_USERNAMES` — usernames через запятую, без `@`;
- `BOT_RECIPES_PATH` — путь к каталогу рецептов;
- `BOT_PAGE_SIZE` — число рецептов на странице;
- `LOG_LEVEL` — `debug`, `info`, `warn` или `error`.

## Проверки

```bash
make test
make vet
```

Токен в YAML намеренно пуст: без `BOT_TOKEN` приложение завершится с понятной ошибкой конфигурации.

Для контейнерного запуска:

```bash
docker build -t dinner-please-bot .
docker run --rm -e BOT_TOKEN='123456:telegram-token' dinner-please-bot
```
